# NADINVERSE ✦
Personal digital universe website.

## Cara pakai
1. Extract ZIP.
2. Buka `index.html` untuk preview.
3. Upload seluruh isi folder ke repository GitHub.
4. Aktifkan **Settings → Pages → Deploy from branch**.
5. Pilih branch `main` dan folder `/ (root)`.

## Isi
- Futuristic responsive landing page
- About dengan foto
- Project cards
- Interactive skill tree
- XP progress
- Journey timeline
- Personal gallery
- Dark/light mode
- Cursor glow & scroll reveal
- Toast notifications
- Hidden Easter egg (klik "DO NOT CLICK × 7" sebanyak 7 kali)
